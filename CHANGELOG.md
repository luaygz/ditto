# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses
[Semantic Versioning](https://semver.org/spec/v2.0.0.html). The distribution on PyPI is
`ditto-extract`; the import name and the CLI are `ditto`.

## [Unreleased]

## [1.0.0] - 2026-10-27

First release: the full pipeline, both modes, the evaluation harness and the published
benchmarks (SWDE test split with four baselines, SWDE development slice, Common Crawl silver
set, LiveWeb-IE snapshot, synthetic clustering curves).

### Added

- `BUILD_REPORT.md`: what was built, every gate and waiver, LLM spend by phase, next steps.
- `CachedLLM.is_cached`: generation's budget projection leaves out requests already in the
  response cache, so a cached rerun is never refused for lack of budget.

### Changed

- Version 1.0.0.

### Fixed

- `.env` is read from the working directory (search upward) for every setting, also when
  installed.
- A YAML syntax error in `fields.yaml` and a refused overwrite in `ditto synth generate` print one
  `error:` line instead of a traceback.
- `--workers` reaches union-page building.
- `--tail spec` generates specs for tail clusters the probe never mapped; `--tail direct` skips
  tail clusters that already have a final spec.
- Review-triggered repairs use the run's pinned models and `--no-cache` (`ditto review
  --no-cache`).
- Default run-directory names keep dots (`pages.v2`); WARC inputs drop `.warc`/`.warc.gz`.

## [0.5.0] - 2026-10-27

Benchmarks complete; v0.5 gate passed: every README number is regenerated by `ditto eval run`
with pinned model ids (final cached reruns of all 18 configs) and written by `eval/report.py`;
spend is recorded per evaluation.

### Added

- Published results for every evaluation config, regenerated by cached reruns with the `canon`
  column (metric version 2) and rewritten into `README.md` and `docs/benchmarks.md` by
  `eval/report.py`.
- SWDE test split: ditto (prompted), AutoScraper on one site per vertical, Crawl4AI
  `generate_schema` on the sites finished within its budget; LiveWeb-IE snapshot: ditto
  (prompted) per query complexity type; Common Crawl silver set: ditto, the naive per-page
  baseline and Crawl4AI.
- `eval/report.py`: every baseline row is followed by ditto scored on exactly the same sites
  and pages (the baseline's seeded sample where it ran on one), recomputed from ditto's
  per-site results; the headline chart joins each baseline to that ditto point; tables show F1
  normalized, raw and canon (`–` for results older than metric version 2) and how many labeled
  pages the LLM saw; schema precision of unprompted mode; Common Crawl downloads against plan
  and the label-noise check per domain and field; a generated reproduction table of every config;
  a generated limitations list (samples, site coverage, Common Crawl cap, silver-label noise,
  LiveWeb-IE coverage, synthetic separability, SWDE label problems, extraction speed against the
  target); spend as the LLM cost of the published runs and as billed in the kept runs.
- `eval/report.py --spend-by-phase`: the LLM ledger per build phase, between the release tags.
- README limitations section; `docs/benchmarks.md` with one command per config, the
  like-for-like rule, the spend accounting and the schema-precision judgment file.

### Changed

- README: the metrics description covers the three match columns; the 30-second example
  installs from a clone until the PyPI release.
- `docs/cli.md`, `docs/python-api.md` and `docs/how-it-works.md` checked against the code and
  `--help` (stage behavior, checkpoints, budget handling, configuration variables, the stage-7
  merge rule, the LLM call layer).
- `eval/configs/swde_test_crawl4ai.yaml` lists the SWDE test sites Crawl4AI finished within
  budget, so the config reruns from cache.
- CI: numpy 2.5 typing fixes; CLI tests strip ANSI codes (Typer forces colour on GitHub
  Actions).

### Fixed

- Float tolerance in the Common Crawl back-off cap test (flaky on macOS).

## [0.4.0] - 2026-10-27

Unprompted mode evaluated; v0.4 gate passed (schema precision on 10 development sites, judged by
the build agent; clean-environment install and the README example).

### Added

- Unprompted evaluation: LLM field names aligned to label names per key and per table column;
  schema precision recomputed on every run from the committed per-field verdicts in
  `eval/judgments/swde_dev_schema_precision.json` (judged by the build agent, not a human),
  with unjudged and stale verdicts listed.
- `canon` match column (metric version 2): accents, a trailing `|`, digit grouping in long
  identifiers and joined multi-values, derived from an analysis of the SWDE development-slice
  misses only (`eval/analysis/swde_dev_misses.*`) and frozen before any test set was rescored.
- SWDE test baselines: hand-written XPath wrappers for five sites and the naive per-page LLM on
  seeded 10-page samples.
- Price entry for `gpt-6.1-terra`; evaluations stay pinned to `gpt-6.1-sol` and
  `gpt-5.4-mini`.
- v0.4 gate results (`eval/results/swde_dev_unprompted/`).

## [0.3.0] - 2026-10-27

Prompted extraction end to end; v0.3 gate passed: on the SWDE development slice ditto is within
5 points of the naive per-page baseline on the same seeded 50-page samples, at under 1% of its
tokens per page.

### Added

- v0.3 gate results (`eval/results/swde_dev_ditto/20261027T102344Z`, against
  `eval/results/swde_dev_naive/20261027T085024Z`).

## [0.2.0] - 2026-10-27

Analysis and union pages; v0.2 gate passed: every optional synthetic field appears in its
template's union page, and every SWDE development-slice union page is under 30k tokens.

### Added

- Results tables in `README.md` and `docs/benchmarks.md` generated by `eval/report.py` between
  `<!-- results:<section>:start/end -->` markers (SWDE, Common Crawl silver set with named
  domains, LiveWeb-IE, clustering curves, union-page gate, spend per evaluation, models and
  prompt versions), read from the latest results of each evaluation config; configs without
  results read "not run yet". `eval/report.py --check` fails when a table is out of date.
- `docs/cli.md`, `docs/benchmarks.md` and `docs/python-api.md`.
- Union-page gate evaluations (`eval/configs/union_gate_*.yaml`).
- CLI: `ditto run --probe-llm` help text; expected failures (including an exceeded LLM budget,
  reported with its totals, and a checkpoint without a terminal and without `--yes`) print one
  `error:` line and exit 1; usage errors (missing source paths, prompted mode without
  `--schema`, an invalid `--tail` per command) exit 2 before any work; `verify` warns and still
  finalizes specs when repairs stop on the budget.
- Baselines fall back to the default service tier when Flex has no capacity and report pages
  that got no answer.
- Baseline runs record their prompt version (`BaselineOutput.prompt_version`) in `meta.json`.
- `DITTO_MP_START=fork|spawn|forkserver` overrides the worker start method (default `fork` on
  Linux, `spawn` elsewhere); `make test-spawn` runs the suite with spawned workers.
- `make docs` (spec schema docs), `make report` (`eval/report.py`) and `make install-check`
  (wheel in a clean virtual environment).
- Integration test: the fixture site through `ditto run --yes` offline with recorded LLM
  responses (`tests/fixtures/llm/`), network blocked, recall checked against the sidecars.
- Evaluation stops at any stage (`until: union`) with per-template union tokens and
  optional-field coverage; union-gate results (`eval/results/union_gate_*`).
- Synthetic clustering curves: one stress parameter at a time from the defaults, 10k pages per
  point, frozen seed 1 (`eval/results/synth_curves/`).
- SWDE development-slice naive baseline on all 16 sites; the earlier partial runs are kept for
  the audit trail.
- Extraction speed bench `eval/bench/speed.py` (no LLM).
- Datasets: LiveWeb-IE snapshot audited (usable sites and a concrete exclusion reason per
  excluded site); polite Common Crawl downloader (one request at a time, at least one second
  apart, back-off on 403/429/503, resumable journal) with the cap lowered to 2,500 pages per
  domain after Common Crawl's firewall blocked concurrent fetching; label fixes; noise check on
  the downloaded pages and on the selection sample.

### Changed

- Union pages: a field candidate missing from the 100-page base sample is searched for in the
  rest of the analysis sample (`union/<template>.json` `searched_pages`); missing labeled rows
  are spliced as rows of their own and label-value pairs sharing one path with their parent;
  rare table value cells (classed noise) are shown and annotated.
- `confirm --yes` mappings are suggestions, not binding: every mapped field records whether a
  person chose it (`user`) or the probe's proposal was accepted unseen (`auto`); generation binds
  only `user` choices and passes `auto` ones as ranked suggestions (`prompts/specgen.v2.md`,
  which also asks for values copied as shown).
- Probe matcher fixes; a cluster is split only on fields its pages verifiably lack (selector
  errors never split a cluster); repairs are kept only when they leave passing values unchanged;
  two more key-value row patterns.
- Union pages: budget-aware splicing (most frequent candidates first, splices that hide another
  candidate undone), rows spliced for values inside text, the 30k-token cap always holds.
- Speed: raw-bytes parsing, id-anchored selector evaluation, plain elements during extraction,
  fast WARC payload reads; XML control characters sanitized completely; `normalize-space()`
  treats no-break spaces as spaces in ditto's runner.
- Evaluation configs sized to the LLM budget: naive-baseline page samples (SWDE test 10 pages
  per site, Common Crawl 20 per domain), AutoScraper on one SWDE test site per vertical, spend
  caps per evaluation.
- `docs/how-it-works.md` corrected against the code (encoding order, LSH threshold and URL
  tie-break, analysis rules, union page building, verification and repair details, checkpoint
  behavior).

## [0.1.0] - 2026-10-26

First tagged version: every stage of the pipeline, the evaluation harness and the v0.1 gate
(clustering on synthetic sites).

### Added

- Repository skeleton: `uv`/hatchling `src/` layout, MIT license, `make check` (ruff, ruff
  format, `mypy --strict`, pytest with coverage), CI workflow, contributing and release guide.
- Shared contracts: run-directory layout (`ditto.run`), structural paths and page cleaning,
  value type checks.
- Ingest of HTML directories (optional `urls.tsv`) and WARC files into `pages.sqlite`, with
  encoding detection and duplicate removal.
- Fingerprinting (CSR fingerprint store) and template clustering: exact signature groups, chrome
  filter, MinHash LSH, exact Jaccard confirmation, URL-pattern tie-break; ARI, purity and
  over/under-merge metrics.
- Cluster analysis: path statistics, candidate classification, label hints, key-value and
  record-table detection.
- Union page synthesis: base-page choice, aligned splicing, comment annotations, collapse by
  variant, pruning, token budget.
- Spec format: Pydantic models with generated JSON Schema (`docs/spec.schema.json`,
  `docs/spec-format.md`), an XPath 1.0 tokenizer lint, the closed transform grammar and a fast
  header-addressed column runner; `Spec.load(path).apply(html)`.
- LLM layer: settings, model auto-selection, OpenAI-compatible and Anthropic adapters, response
  cache, retries, usage ledger, budget guard, structured JSON with one validated retry; flex-tier
  calls billed at the tier multiplier.
- Spec generation (prompted and unprompted), schema proposal and direct long-tail extraction,
  with versioned prompts (`prompts/*.v1.md`).
- Verification and repair: candidate scoring, winner selection, repair calls, path-induced
  fallback, cluster merge and split; extraction to JSONL and the run report.
- Checkpoints: probe (offline matcher, optional small-model call), confirm, review with golden
  samples.
- CLI (Typer) and the Python `Site` API wired to the stage contracts.
- Synthetic site generator with ground truth, default and fixture parameters, and the committed
  200-page fixture site.
- Evaluation harness (`ditto eval run`): metrics, dataset protocol, configs, report charts, and
  baselines (naive per-page LLM, Crawl4AI `generate_schema`, AutoScraper adapter, five
  hand-written SWDE wrappers).
- Datasets: SWDE download and verification, manifest, dev/test split and field descriptions;
  Common Crawl silver set selection (8 domains, 4 verticals), capture index and
  download/label/noise-check scripts; LiveWeb-IE release check, polite snapshot fetcher and
  fields.
- v0.1 gate results for the synthetic default site at 10k and 100k pages
  (`eval/results/synth_default`, `eval/results/synth_scale`).
